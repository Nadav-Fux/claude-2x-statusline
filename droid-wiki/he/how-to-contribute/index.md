# איך לתרום

זהו פרויקט המתוחזק על ידי מתחזק יחיד. תרומות יתקבלו בברכה באמצעות pull requests ב-GitHub.

## עבודה בבסיס קוד זה

- קראו את [תבניות ומוסכמות](patterns-and-conventions.md) לפני ביצוע שינויים. עקרון "לעולם לא לקרוס את הקורא" ודרישות הזהות בין שלושת המנועים הן המוסכמות החשובות ביותר.
- קראו את [תהליך הפיתוח](development-workflow.md) למחזור העבודה של branch, code, test, PR.
- ראו [בדיקות](testing.md) להרצת 138 בדיקות Python ו-8 בדיקות Node.js.
- ראו [דיבאגינג](debugging.md) לבעיות נפוצות ושלבי פתרון.
- ראו [כלים](tooling.md) למערכת ה-build ו-linting.

## מגבלות מרכזיות

1. **זהות בין שלושה מנועים** — כל תכונת statusline חייבת לעבוד גם במנוע Python וגם במנוע Node.js. מנוע ה-Bash מצומצם בכוונה.
2. **תבניות דו-לשוניות** — תבניות ניקוד narrator חדשות דורשות גם שדה `text` וגם שדה `text_he`. בדיקה מבנית אוכפת זאת.
3. **תאימות ל-Windows** — בדקו שינויים מול טיפול הנתיבים ב-Windows ב-`lib/resolve-runtime.sh`. דחו stubs של WindowsApps.
4. **כשל שקט** — מנועים ו-hooks לעולם לא יקרסו. עטפו את כל הלוגיקה בטיפול בשגיאות שמתנוון בחינניות.
5. **כתיבה אטומית** — קבצי state חייבים להיכתב אטומית (tmpfile + rename).
