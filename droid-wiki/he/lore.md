# היסטוריה

היסטוריית הפיתוח של claude-2x-statusline, משוחזרת מערכי changelog, הודעות commit והערות בקוד.

## תקופות

### הבנייה הראשונית (לפני אפריל 2026)

הפלאגין התחיל כשורת סטטוס פשוטה המציגה מידע על המודל ואחוז ההקשר. ערכי ה־changelog המוקדמים ביותר (19 באפריל 2026) מתארים תכונות שכבר היו משמעותיות, מה שמרמז שהפיתוח הראשוני התבצע לפני שמערכת ה־changelog הונהגה.

### מרוץ תכונות: 19 באפריל 2026

שש תכונות שוחררו ביום אחד, לכל אחת פוסט changelog משלה:

- **מדדי חלון מתגלגל** — קצב השריפה עבר מממוצעים מצטברים לחלון מתגלגל של 10 דקות עם מגני spike. ההחלטה נבעה מערכים אבסורדיים כמו $800/hr שהופיעו כאשר קריאת API יקרה בודדת פגעה בחלון.
- **Narrator hook** — הונהגה מערכת התובנות הדו-שכבתית (מנוע חוקים + Haiku אופציונלי). מנוע החוקים תוכנן לפעול תמיד ומתחת ל-50ms כדי לא להוסיף latency לשליחת הפרומפט.
- **פקודת `/explain`** — נוספה תיעוד פלח-אחר-פלח ל-doctor, מה שהפך 18 פלחים למתועדים-עצמאית.
- **תיקוני באגים** — שיא UTC של שבת היה בלתי נראה למשתמשי UTC+3 ביום ראשון מקומי (באג הגלישה בין אזורי זמן). ארבעה באגי overflow מספריים נפרדים תוקנו: $1.2M/hr, $55B עלות חזויה, 29M% הקשר, $813/hr קצב שריפה.
- **טלמטריית התקנה** — פוסט שקיפות מלאה המתעד את המטענים (payloads) המדויקים, מה שנאסף ומה לא, ומנגנון הביטול.
- **חיזוק Windows** — דחיית stub binaries של Microsoft Store, המרת cygpath, אכיפת UTF-8 וגילוי Python נייד.

### ליטוש והרחבה (20-21 באפריל 2026)

- **Narrator דו-לשוני** (20 באפריל) — זיהוי אוטומטי של עברית ממשתני סביבת locale. כל 18 תבניות התובנות קיבלו תרגומי `text_he`. נוספה בדיקה מבנית האוכפת את החוזה הדו-לשוני על תבניות חדשות.
- **אבחון doctor עשיר** (20 באפריל) — מערכת פרטיות בת 3 רמות (full/minimal/off) עם העלאה אוטומטית של דוחות מחוטאים בעת כשל. קודי אבחון יציבים לכל מכונה.
- **Plugin manifest** (20 באפריל) — עודכן ל-v2.2.0, נוסף רישום hooks ל-`plugin.json` כך שהתקנות מ-marketplace יחברו את ה-narrator אוטומטית.
- **זוגיות Node** (21 באפריל) — השלמת הפורט של ה-narrator ל-Node.js, המעניק למשתמשי Node בלבד את אותו מנוע חוקים כמו למשתמשי Python. הערות ה-narrator מוסגרו ב-`//// ... ////` להבחנה ויזואלית.

### תחזוקה (מאי 2026)

- **תיקון זיהוי narrator hook ב-doctor** (2 במאי) — תוקן false positive ב-Windows/Git Bash שבו hooks מותקנים דווחו כחסרים. התיקון קורא את `settings.json` דרך stdin, עובר על מבנה ה-hooks המקונן ומנרמל נתיבי MSYS מסוג `/c/...`.
- **תיקוני ניתוב ומטא-נתונים** (1 במאי) — שוחזר הניתוב `/failures` ב-worker, הורחב קבלת קודי האבחון ל-hex בן 8 תווים, תוקן ציטוט נתיבים ב-install.sh.

### תוסף VS Code (יוני 2026)

תוסף VS Code עודכן ל-v0.2.0 (11 ביוני 2026) עם תמיכת אריזה ל-vsce. התוסף קורא נתונים חיים מקבצי פלט שורת הסטטוס ומרנדר פסי סוללה בשורת הסטטוס של העורך.

### השלמת זוגיות Node של ה-narrator (14 ביוני 2026)

ה-commit האחרון השלים את זוגיות ה-narrator ב-Node, הוסיף לוגיקת fallback ל-hooks, סנכרן גרסאות בין קבצי ה-manifest ותיקן תיעוד.

## התכונות הוותיקות ביותר

- **Dispatch תלת-מנועי** (`statusline.sh` + `lib/resolve-runtime.sh`) — מדרג העדיפויות Python/Node/Bash הוא הארכיטקטורה המרכזית מאז ההתחלה.
- **מערכת schedule** — ה-`schedule.json` המתעדכן מרחוק עם המרת אזור זמן אוטומטית הייתה אחת התכונות הראשונות ונותרת התכונה המרכזית.
- **פלטת צבעי ANSI** — קבועי הצבע המשותפים (RST, BOLD, GREEN, BG_GREEN וכו') מופיעים באופן זהה בכל שלושת המנועים.

## תכונות שהוצאו משימוש

- **Throttling בשעות השיא** — Anthropic הסירה את ה-throttling בשעות השיא ב-2026-05-06. הפלח `peak_hours` נשמר רק למשתמשי custom-tier שעדיין רוצים רמז לוח זמנים היסטורי. הערך `mode` ב-schedule שונה ל-`"normal"`.
- **דגל `--report` ב-doctor** — יצא ל-no-op כשמערכת ההעלאה האוטומטית החליפה דיווח ידני. הדגל עדיין מתפרש אך אינו עושה דבר.

## שכתובים מרכזיים

- **פורט ה-narrator ל-Node** (21 באפריל 2026) — צינור ה-narrator (engine, observations, scoring, memory, Haiku) הוסב מ-Python למודול `narrator-node.js` יחיד ועצמאי. זה העניק לסביבות Node בלבד זוגיות narrator מלאה.
- **שכתוב חלון מתגלגל** (19 באפריל 2026) — חישוב קצב השריפה שונה מממוצעי סשן מצטברים לחלון מתגלגל של 10 דקות. הגישה הישנה יצרה מספרים מטעים במהלך סשנים עם פעילות פרצים.

## אירועים בולטים

- **חטיפת על ידי token-optimizer** — תיקון ה-`restore-statusline` ב-doctor קיים משום שפלאגין אחר חטף את סטנזת ה-`statusLine` ב-`settings.json`. ה-doctor מזהה זאת ויכול לשחזר את הפקודה הנכונה.
- **באגי spike מספריים** — ארבעה באגי overflow נפרדים ($1.2M/hr, $55B, 29M%, $813/hr) נגרמו כולם ממחסור במגינים בחישובי קצב. הם תוקנו באמצעות מגני minimum-span ו-maximum-plausible-rate שכעת מגנים על כל החישובים המתגלגלים.
