# אבטחה

## גבולות אמון

הפלאגין פועל כולו מקומית. הוא קורא מטא-נתוני סשן מ-stdin של Claude Code, כותב קבצי state ל-`~/.claude/`, ושולח טלמטריה אנונימית ל-Cloudflare Worker. שום מידע רגיש אינו עוזב את המכונה.

## חיטוי נתונים

לפני כל שליחת טלמטריה, הנתונים מחוטאים בצד הלקוח:

| קלט | מחוטא ל |
|-------|-------------|
| נתיבי תיקיית הבית | `~/` |
| שמות משתמש | `<user>` |
| שמות מארח | `<host>` |

שום תוכן שיחה, תוכן קבצים, קוד מקור, מפתחות API או מזהי סשן אינם מועברים. מטען הטלמטריה מוגבל ל: מזהה אנונימי (hash hex), גרסה, מנוע, tier, מערכת הפעלה וסוג אירוע.

## מזהה טלמטריה

מזהה הטלמטריה הוא מחרוזת hex בת 16 תווים הנוצרת מ-`secrets.token_hex(8)` (או `openssl rand -hex 8` כ-fallback). זהו מזהה אקראי, לא hash של מידע מזהה. הוא מאוחסן ב-`~/.claude/.statusline-telemetry-id` עם מצב 600 (קריאה/כתיבה לבעלים בלבד).

## טיפול במפתח API

שכבת ה-Haiku האופציונלית של ה-narrator משתמשת ב-`ANTHROPIC_API_KEY` מהסביבה. המפתח:

- לעולם אינו נשמר לדיסק על ידי הפלאגין
- לעולם אינו נכלל בטלמטריה
- מועבר רק ל-constructor של ה-client של Anthropic SDK

תוסף VS Code קורא אישורי OAuth מ-`~/.claude/.credentials.json` (נכתב על ידי Claude Code עצמו, לא על ידי פלאגין זה) כדי לשלוף נתוני rate limit מ-API של Anthropic.

## ביטול השתתפות

ניתן להשבית את הטלמטריה לחלוטין:

```json
// ~/.claude/statusline-config.json
{ "telemetry": false }
```

או באמצעות משתנה סביבה:

```bash
export STATUSLINE_DISABLE_TELEMETRY=1
```

כאשר מושבת, שום פינג אינו נשלח, לעולם. ראו [טלמטריה](features/telemetry.md) למודל הפרטיות המלא.

## פרטיות דוח ה-doctor

דוחות אבחון של ה-doctor (נשלחים רק עם כשל בבדיקה עם פרטיות `full`) מחוטאים לפני העלאה ונמחקים אוטומטית לאחר 30 יום. קוד האבחון הוא hash חד-כיווני של hostname + username, יציב לאורך הרצות אך אינו הפיך לזיהוי המשתמש.

## קריאות רשת חיצוניות

| קריאה | מתי | יעד |
|------|------|-------------|
| שליפת schedule | כל 3 שעות | `raw.githubusercontent.com`‏ (GitHub raw) |
| פינג טלמטריה | יומי / באירועים | `statusline-telemetry.nadavf.workers.dev` |
| Haiku API | כל 5 פרומפטים או 15 דקות | `api.anthropic.com`‏ (רק אם מוגדר מפתח API) |
| Rate limit API‏ (VS Code) | כל 30 שניות | Anthropic OAuth API‏ (רק אם אישורים זמינים) |

כל קריאות הרשת נכשלות בשקט. שום קריאה אינה חוסמת את שורת הסטטוס או ה-narrator.
