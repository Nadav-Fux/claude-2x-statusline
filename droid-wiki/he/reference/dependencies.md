## תלויות זמן ריצה

### מנוע Python

| תלות | נדרש | מטרה |
|------------|----------|---------|
| Python 3.6+ | כן‏ (3.9+ ל-narrator) | זמן ריצה |
| `tzdata` | מומלץ | נתוני אזור זמן במערכות ללא מסד נתוני tz של המערכת |

### מנוע Node.js

| תלות | נדרש | מטרה |
|------------|----------|---------|
| Node.js LTS | כן | זמן ריצה |

אין תלויות npm למנוע עצמו.

### מנוע Bash

אין תלויות חיצוניות מעבר ל-Bash 4+.

### שכבת Haiku של ה-narrator‏ (אופציונלי)

| תלות | נדרש | מטרה |
|------------|----------|---------|
| חבילת `anthropic` ב-Python | רק ל-Haiku | Anthropic SDK לקריאות claude-haiku-4-5 |
| משתנה סביבה `ANTHROPIC_API_KEY` | רק ל-Haiku | אימות API |
