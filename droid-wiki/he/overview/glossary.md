# מילון מונחים

| מונח | הגדרה |
|------|------------|
| **Tier** (רמה) | רמת תצוגה ששולטת באילו מקטעים ירונדרו: `minimal` (שורה אחת), `standard` (2 שורות), או `full` (4 שורות) |
| **Segment** (מקטע) | אלמנט סטטוסליין בודד (למשל `model`, `context`, `rate_limits`, `cost`, `burn_rate`) |
| **Mode** (מצב) | מצב רינדור בתוך רמה: `minimal` או `full`. שולט אם שורות לוח הבקרה (timeline, rate bars, metrics) ירונדרו מתחת לשורה 1 |
| **Narrator** (מספר) | מערכת תובנות שמוזרקת דרך hook ומציגה עצות בשפה טבעית מעל שורת הפקודה. שתי שכבות: מנוע כללים (תמיד פעיל) ו-LLM Haiku אופציונלי |
| **Rules engine** (מנוע כללים) | מערכת ניקוד מבוססת תבניות ב-`narrator/scoring.py` שמעריכה observations על 4 צירים (דחיפות, חידוש, יכולת פעולה, ייחודיות) ובוחרת עד 2 תובנות |
| **Haiku layer** (שכבת Haiku) | נרטיב מועשר LLM אופציונלי שמשתמש ב-`claude-haiku-4-5`. מופעל כל 5 פקודות או 15 דקות כש-`ANTHROPIC_API_KEY` מוגדר |
| **Schedule** (לו"ז) | קובץ JSON מרוחק (`schedule.json` ב-GitHub) ששולט בתוויות שעות שיא, באנרים, הודעות על גרסאות, ו-feature flags |
| **Rolling window** (חלון מתגלגל) | ring buffer ל-60 דקות ב-`~/.claude/statusline-state.json` ששומר עלות, ספירות טוקנים ומדדי מטמון לכל דגימה |
| **Burn rate** (קצב שריפה) | מהירות ההוצאה ($/hr) שמחושבת מהחלון המתגלגל. מינימום טווח 3 דקות, מכסת סניטי $200/hr |
| **Cache reuse** (ניצולת מטמון) | אחוז טוקני קלט שמוגשים מהמטמון. מוצג עם דלתא ומצב idle/active |
| **Doctor** (דוקטור) | כלי אבחון (`doctor/doctor.sh`) שבודק את בריאות ההתקנה, מסביר מקטעים, ומחיל תיקונים |
| **Diagnostic code** (קוד אבחון) | מזהה hex יציב לכל מכונה שמוצג בכל הרצת doctor. משמש למתאם טלמטריה אנונימית |
| **Runtime resolver** (פותר ה-runtime) | לוגיקה משותפת ב-`lib/resolve-runtime.sh` שמאתרת interpreter עובד של Python או Node, ודוחה stubs של Windows Store |
| **Wire-json** | ספריית merge/query ל-JSON חוצת-פלטפורמות שמשמשת את המתקינים (`lib/wire-json.sh`, `lib/Wire-Json.ps1`) |
| **Battery bar** (סוללת חיווי) | מחוון מגבלת-קצב חזותי שמשתמש בתווי block של Unicode כדי להציג אחוז ניצולת |
| **Framed text** (טקסט ממוסגר) | פלט המספר שעטוף בתוחמים `//// ... ////` כדי שיבלוט ויזואלית מהקונטקסט הרגיל של שורת הפקודה |
| **Peak hours** (שעות שיא) | לו"ז היסטורי למועדים שבהם Anthropic ויסתה את צריכת מכסת 5 השעות. הוסר ב-2026-05-06; המקטע נשמר למשתמשי custom-tier |
| **Workflow** (תזרים עבודה) | יחידת הרצה של subagent ב-Claude Code. ה-`statusline` קורא מצב workflow חי ומושלם מתיקיות הסשן |
