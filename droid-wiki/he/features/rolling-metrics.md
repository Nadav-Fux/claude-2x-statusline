# מדדים מתגלגלים

## מטרה

מערכת המדדים המתגלגלים מספקת קצב שריפה בזמן אמת ($/שעה), אחוז שימוש חוזר במטמון, והערכות דלדול הקשר. במקום להשתמש בממוצעי סשן לכל אורך החיים, היא מחשבת קצבים על גבי חלון הזזה כך שעליות רגעיות לא מעוותות את המספרים.

## ארכיטקטורה

מאגר טבעתי בן 60 דקות ב-`~/.claude/statusline-state.json` מאחסן דגימות. כל דגימה לוכדת תמונת מצב ברגע נתון:

```json
{
  "t": 1718400000,
  "cost": 4.23,
  "tokens_in": 150000,
  "tokens_out": 32000,
  "cache_read": 120000,
  "cache_creation": 8000
}
```

מנוע סטטוס הליין מוסיף דגימה בכל מחזור רינדור. דגימות ישנות מ-60 דקות נפלטות בכל כתיבה.

## חישוב קצב שריפה

קצב השריפה משתמש בחלון של 10 דקות כברירת מחדל. האלגוריתם:

1. מסנן דגימות ל-`window_min` הדקות האחרונות
2. מחשב את הפרש העלות בין הדגימה הישנה ביותר לאחרונה
3. מחלק בשעות שחלפו
4. מחיל שומרי שפיות

שומרים מונעים מעליות להשחית את התצוגה:

| שומר | ערך | הסבר |
|-------|-------|-----------|
| טווח מינימלי | 180 שניות (3 דקות) | קריאת API יקרה אחת יכולה ליצור עליה של $800/שעה |
| קצב מקסימלי סביר | $200/שעה | כל דבר גבוה יותר נחשב לעליה; חוזר לממוצע הסשן |
| הפרש עלות שלילי | מחזיר `None` | איפוס סשן או שחיתות מצב |

אם הקצב המתגלגל מחזיר `None` (נתונים לא מספיקים או זוהתה עליה), המנוע חוזר לקצב הסשן לכל אורך החיים.

## מדדי מטמון

שימוש חוזר במטמון מציג איזה חלק מטוקני הקלט הגיעו ממטמון הפרומפט:

```
cache reuse 96% ↑2.3k saving
```

- האחוז הוא `cache_read / total_input_tokens * 100`
- הדלתא (`↑2.3k saving`) מציגה טוקני `cache_read` שנוספו ב-5 הדקות האחרונות
- כשהמטמון במנוחה, התצוגה מראה `cache reuse 96% idle`
- המילה "reuse" מדגישה שקריאות מטמון עולות בערך 10% מקלט רגיל

## הערכת דלדול הקשר

השדה `ctx_mins_left` משערך מתי חלון ההקשר יתמלא, בהתבסס על קצב גידול ההקשר על פני החלון המתגלגל. זה מזין את אזהרות ה"ההקשר מתמלא" של הנרטור.

## מימוש כפול

למצב המתגלגל יש מימושים מקבילים שחייבים להישאר מסונכרנים:

| קובץ | שפה | בשימוש על ידי |
|------|----------|---------|
| `lib/rolling_state.py` | Python | `engines/python-engine.py`, `narrator/observations.py` |
| `lib/rolling_state.js` | JavaScript | `engines/node-engine.js`, `narrator/narrator-node.js` |

שניהם משתמשים באותו פורמט קובץ, אותם קבועים (`MAX_AGE_SECS = 3600`, `MIN_SPAN_SECS = 180`, `MAX_PLAUSIBLE_RATE = 200.0`), ואותו דפוס כתיבה אטומית.
