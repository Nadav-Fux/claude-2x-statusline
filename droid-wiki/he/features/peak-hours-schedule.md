# שעות שיא ולוח זמנים

## מטרה

מערכת הלוח זמנים מאפשרת למתחזק לדחוף שינויי קונפיגורציה (חלונות שעות שיא, באנרים פרסומיים, התראות גרסה, דגלי תכונות) לכל סטטוסי הליין הרצים בלי לדרוש מהמשתמשים לעדכן. קובץ JSON ב-GitHub נשלך כל 3 שעות ונשמר במטמון מקומי.

## פורמט לוח זמנים

קובץ `schedule.json` בשורש הריפוזיטורי מגדיר את הקונפיגורציה המרוחקת:

```json
{
  "v": 5,
  "mode": "normal",
  "default_tier": "full",
  "peak": {
    "enabled": true,
    "tz": "UTC",
    "days": [1, 2, 3, 4, 5],
    "start": 13,
    "end": 19,
    "label_peak": "Peak",
    "label_offpeak": "Off-Peak"
  },
  "banners": [
    { "text": "...", "expires": "2026-06-15", "color": "red" }
  ],
  "release": {
    "latest_version": "2.2.0",
    "minimum_version": "2.1.0",
    "command": "/statusline-update"
  },
  "features": {
    "show_peak_segment": true,
    "show_rate_limits": true,
    "show_timeline": true
  }
}
```

ראו [סיכום פורמט לוח זמנים](../reference/schedule-format.md) לכל השדות.

## מחזור שליפה ומטמון

1. המנוע בודק את `~/.claude/statusline-schedule.json` לעותק במטמון
2. אם גיל המטמון עולה על `schedule_cache_hours` (ברירת מחדל 3), שולף מ-URL גולמי של GitHub
3. השליפה משתמשת ב-HTTPS עם timeout של 5 שניות
4. בכישלון שליפה, חוזר לעותק במטמון או לברירות מחדל מובנות
5. הלוח זמנים מנורמל: שדות חסרים ממולאים מ-`DEFAULT_SCHEDULE`

השליפה אינה חוסמת בעת כישלון. לוח זמנים פגום או null חוזר לברירות מחדל במקום לקרוס את סטטוס הליין.

## המרת אזור זמן אוטומטית

שעות שיא מוגדרות באזור זמן מקור (כיום UTC). המנוע ממיר אותן לאזור הזמן המקומי של המשתמש לתצוגה:

- משתמש ב-`datetime.now(timezone.utc)` ובזיהוי אזור זמן מקומי
- מטפל במעברי שעון קיץ/חורף (DST)
- מטפל נכון בגלישת שבת-ראשון חוצה-אזורי זמן (שיא של שבת בפסיפיק שנכנס ליום ראשון עבור משתמשי UTC+3)

התיקון החוצה-אזור זמן הזה היה תיקון באג משמעותי (ראו [lore](../lore.md)). גרסאות קודמות לא זיהו את חלון הגלישה.

## התנהגות תצוגה

כש-`mode` הוא `"normal"` (המצב הנוכחי), שורת ציר הזמן מוסתרת לחלוטין. פסי מגבלות תעריף ומדדים עדיין מרונדרים ברמת `full`.

כש-`mode` הוא `"peak_hours"`, ציר הזמן מרנדר פס אופקי שמציג את חלון השיא בזמן המקומי של המשתמש, עם סמן מיקום ל"עכשיו".

צבעי מקטע שיא:

| מצב | צבע | תנאי |
|-------|-------|-----------|
| מחוץ לשיא | תג ירוק | מחוץ לחלון השיא |
| שיא (עמוק) | תג אדום | נשארו שעות רבות בשיא |
| שיא (מסתיים) | תג צהוב | נותרו פחות מ-1-2 שעות |
| שיא (כמעט נגמר) | תג ירוק | נותרו פחות מ-30 דקות |

## מערכת באנרים

באנרים הם הודעות פרסומיות או אינפורמטיביות עם תאריך תפוגה. המנוע מסנן באנרים שפג תוקפם לפני התצוגה. מספר באנרים יכולים להיות פעילים בו-זמנית. צבעים: `red` (דחוף), `yellow` (מידע).

## בדיקת גרסאות

בלוק `release` מניע התראות עדכון:

- `latest_version` — מוצג כשגרסת המשתמש נמוכה מזו
- `minimum_version` — מוצג כ"נדרש" כשגרסת המשתמש נמוכה מזו
- השוואת גרסאות משתמשת בניהול גרסאות סמנטי (major.minor.patch)

## קובצי מקור מרכזיים

| קובץ | מטרה |
|------|---------|
| `schedule.json` | מקור לוח זמנים מרוחק (נשלך על ידי כל סטטוסי הליין) |
| `engines/python-engine.py` | שליפת לוח זמנים, נירמול, המרת אזור זמן |
| `engines/node-engine.js` | שקילות Node.js לטיפול בלוח זמנים |
| `vscode/extension.ts` | טיפול בלוח זמנים של תוסף VS Code |
