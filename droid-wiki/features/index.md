# Features

The plugin provides six user-visible capabilities. Each is documented in its own page below.

- [Statusline tiers](statusline-tiers.md) — The 3-tier display system (minimal, standard, full) and segment rendering
- [Rolling metrics](rolling-metrics.md) — Burn rate, cache reuse, and the 60-minute rolling window
- [Narrator](narrator.md) — Two-layer insight system: rules engine plus optional Haiku LLM
- [Peak hours and schedule](peak-hours-schedule.md) — Remote-updatable schedule with auto-timezone conversion
- [Doctor diagnostics](doctor.md) — Installation health checks, auto-fix, and segment explanations
- [Telemetry](telemetry.md) — Anonymous usage tracking with full transparency and opt-out
